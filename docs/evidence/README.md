# Obrazy z testów

Niezmienione obrazy ekranu z lokalnego emulatora AOSP API 36. Dane są sztucznymi danymi fixture.

- `popup-main.png`: małe główne okienko 0.2.0.
- `popup-text.png`: edytor w popupie 0.2.0.
- `mouse-selection.png`: fragment zaznaczony myszą, skopiowany i odczytany przez niezależną aplikację.
- `narrow-panel.png`: pionowy pasek pływający 0.2.0 nad inną aplikacją.
- `accessibility-source.png`: odczyt tekstu z fixture w 0.1.2, bez węzła hasłowego.
- `image-clipboard.png`: niezależny odbiorca zdekodował URI obrazu 1000 × 700 bez uprawnienia do galerii.

To nie są zdjęcia ani testy fizycznego Samsunga / One UI / DeX.
- `popup-accessibility.png`: tekst innej aplikacji w małym oknie 0.2.0.

Wersja 0.3.0:

- `transparency-setting.png`: suwak przezroczystości 0–80%.
- `dot-transparent.png`: zminimalizowana kropka z przezroczystością 40%.
- `panel-transparent.png`: panel po rozwinięciu kropki przy dolnej prawej krawędzi; mieści się na ekranie.
- `popup-transparent.png`: popup po restarcie, z zachowaną przezroczystością 40%.
